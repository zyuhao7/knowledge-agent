# 产品与 API 常见问题

## 如何创建 API Key

登录控制台，进入“设置 - API Key”，点击“新建密钥”。密钥只在创建时显示一次，请立即保存。若怀疑泄漏，应在控制台立即吊销并重新创建。每个账号最多保留 10 个有效密钥。

## 鉴权方式

所有请求需在请求头携带 `Authorization: Bearer <token>`。服务端会校验密钥有效性与权限范围，缺失或无效时返回 401。

## 调用频率限制

免费版默认每分钟 60 次请求，企业版默认每分钟 600 次。超过限制返回 429，并附带 `Retry-After` 响应头。建议客户端采用指数退避重试，避免雪崩。

## 常见错误码

401 表示密钥无效或过期；403 表示无权限访问该资源；404 表示资源不存在；429 表示触发限流；500 表示服务端异常，可安全重试；502/504 表示网关或上游超时，建议退避后重试。

## SDK 与文档

官方提供 Python、Node.js、Go 与 Java SDK。示例代码、OpenAPI 规范与更新日志均发布在文档中心。SDK 默认读取环境变量 `API_KEY`。

## 数据保留策略

默认保留请求日志 30 天。企业版可配置为 7 至 180 天，并支持私有化部署。删除账号后，相关数据在 30 天内完成清除。
